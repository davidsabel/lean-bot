Erst selbst probieren! Klappen Sie die Hilfen nacheinander auf, nur so weit wie nötig.

## Aufgabe 4.1: die Summe der ersten n ungeraden Zahlen 1 + 3 + 5 + ...

<details>
<summary>Tipp 1</summary>

Der Beweis hat genau denselben Aufbau wie `gauss`. Kopiere ihn und passe einen Namen an.

</details>

<details>
<summary>Tipp 2</summary>

In der Zeile `simp only [...]` muss jetzt `ungerade` statt `summe` stehen.

</details>

<details>
<summary>Lösung dieser Aufgabe</summary>

```lean
def ungerade : Nat → Nat
  | 0     => 0
  | n + 1 => ungerade n + (2 * n + 1)
```

</details>

## Aufgabe 4.2: `teilmengen` aus Mission 1. Zeige teilmengen n = 2 ^ n.

<details>
<summary>Tipp 1</summary>

Wieder derselbe Aufbau wie bei `gauss`.

</details>

<details>
<summary>Tipp 2</summary>

In der Zeile `simp only [...]` steht jetzt `teilmengen`.

</details>

<details>
<summary>Lösung dieser Aufgabe</summary>

```lean
def teilmengen : Nat → Nat
  | 0     => 1
  | n + 1 => 2 * teilmengen n
```

</details>

## Aufgabe 4.3: verdopple ändert die Länge der Liste nicht.

<details>
<summary>Tipp 1</summary>

Genau wie `plusEins_laenge`.

</details>

<details>
<summary>Tipp 2</summary>

In der Zeile `simp only [...]` steht jetzt `verdopple` statt `plusEins`.

</details>

<details>
<summary>Lösung dieser Aufgabe</summary>

```lean
theorem laenge_bleibt (xs : List Nat) : (verdopple xs).length = xs.length := by
  induction xs with
  | nil => rfl
  | cons x xs iv =>
      simp only [verdopple, List.length_cons, iv]
```

</details>

## Aufgabe 4.4: Die Summe der verdoppelten Liste ist doppelt so groß.

<details>
<summary>Tipp 1</summary>

Induktion über xs wie eben. Im Fall `cons` hilft `List.sum_cons` (die Summe von x :: xs ist x + Summe von xs).

</details>

<details>
<summary>Tipp 2</summary>

Fall `cons x xs iv`: `simp only [verdopple, List.sum_cons]` und danach `grind`, wie bei `gauss`.

</details>

<details>
<summary>Lösung dieser Aufgabe</summary>

```lean
theorem summe_verdoppelt (xs : List Nat) : (verdopple xs).sum = 2 * xs.sum := by
  induction xs with
  | nil => rfl
  | cons x xs iv =>
      simp only [verdopple, List.sum_cons]
      grind
```

</details>
