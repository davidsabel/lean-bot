## Aufgabe 2.1: A → B → A

<details>
<summary>Tipp 1</summary>

Genau wie `beispiel_zweites`, nur wird diesmal das ERSTE Argument zurückgegeben.

</details>

<details>
<summary>Tipp 2</summary>

`fun a _ => a`

</details>

<details>
<summary>Lösung dieser Aufgabe</summary>

```lean
theorem aufgabe_2_1 (A B : Prop) : A → B → A :=
  fun a _ => a
```

</details>

## Aufgabe 2.2: Kettenschluss

<details>
<summary>Tipp 1</summary>

Drei Argumente: f : A → B, g : B → C und a : A. Wie bei `beispiel_mp` wendet man Funktionen an, diesmal zwei hintereinander.

</details>

<details>
<summary>Tipp 2</summary>

Aus a macht f einen Beweis von B, daraus macht g einen Beweis von C: `fun f g a => g (f a)`

</details>

<details>
<summary>Lösung dieser Aufgabe</summary>

```lean
theorem aufgabe_2_2 (A B C : Prop) : (A → B) → (B → C) → A → C :=
  fun f g a => g (f a)
```

</details>

<details>

## Aufgabe 2.6: A ∨ A → A

<details>
<summary>Tipp 1</summary>

Fallunterscheidung wie in `beispiel_oder`. In beiden Fällen hast du einen Beweis von A.

</details>

<details>
<summary>Tipp 2</summary>

`fun h => match h with | Or.inl a => a | Or.inr a => a` (zwei Zeilen wie im Beispiel)

</details>

<details>
<summary>Lösung dieser Aufgabe</summary>

```lean
theorem aufgabe_2_6 (A : Prop) : A ∨ A → A :=
  fun h => match h with
    | Or.inl a => a
    | Or.inr a => a
```

</details>

## Aufgabe 2.8: Distributivgesetz. Das Gerüst ist schon da.

<details>
<summary>Tipp 1</summary>

Im ersten Fall hast du a : A und b : B, im zweiten a : A und c : C. Wähle mit `left` oder `right` die passende Seite, wie in `beispiel_taktik_oder`.

</details>

<details>
<summary>Tipp 2</summary>

`| inl b => left; exact ⟨a, b⟩` und `| inr c => right; exact ⟨a, c⟩`

</details>

<details>
<summary>Lösung dieser Aufgabe</summary>

```lean
theorem aufgabe_2_8 (A B C : Prop) : A ∧ (B ∨ C) → (A ∧ B) ∨ (A ∧ C) := by
  intro ⟨a, h⟩
  cases h with
  | inl b => left; exact ⟨a, b⟩
  | inr c => right; exact ⟨a, c⟩
```

</details>

## Aufgabe 2.9: De Morgan, eine Richtung

<details>
<summary>Tipp 1</summary>

Beginne mit `intro h` und `constructor` wie in `beispiel_taktik_und`. Dann ist z.B. ¬A zu zeigen, also eine Funktion: `intro a`.

</details>

<details>
<summary>Tipp 2</summary>

Mit a : A hast du `Or.inl a : A ∨ B`, und h macht daraus False: `exact h (Or.inl a)`. Für B genauso mit `Or.inr`.

</details>

<details>
<summary>Lösung dieser Aufgabe</summary>

```lean
theorem aufgabe_2_9 (A B : Prop) : ¬(A ∨ B) → ¬A ∧ ¬B := by
  intro h
  constructor
  · intro a; exact h (Or.inl a)
  · intro b; exact h (Or.inr b)
```

</details>
