## Aufgabe 3.1: Es gibt ein n mit n + n = 26.

<details>
<summary>Tipp 1</summary>

Welche Zahl ist der Zeuge? Dann wie im Beispiel: ⟨Zeuge, rfl⟩.

</details>

<details>
<summary>Tipp 2</summary>

`⟨13, rfl⟩`

</details>

<details>
<summary>Lösung dieser Aufgabe</summary>

```lean
theorem aufgabe_3_1 : ∃ n : Nat, n + n = 26 := ⟨13, rfl⟩
```

</details>

## Aufgabe 3.3: 2n ist immer gerade.

<details>
<summary>Tipp 1</summary>

Wie im Beispiel. Welcher Zeuge k erfüllt 2 * n = 2 * k?

</details>

<details>
<summary>Tipp 2</summary>

`fun n => ⟨n, by omega⟩`

</details>

<details>
<summary>Lösung dieser Aufgabe</summary>

```lean
theorem aufgabe_3_3 : ∀ n : Nat, gerade (2 * n) :=
  fun n => ⟨n, by omega⟩
```

</details>

## Aufgabe 3.4: Ist n gerade, dann auch n + 2.

<details>
<summary>Tipp 1</summary>

Die ersten zwei Zeilen sind genau wie im Beispiel. Nur der Zeuge ändert sich.

</details>

<details>
<summary>Tipp 2</summary>

Aus n = 2 * k folgt n + 2 = 2 * (k + 1). Letzte Zeile: `exact ⟨k + 1, by omega⟩`

</details>

<details>
<summary>Lösung dieser Aufgabe</summary>

```lean
theorem aufgabe_3_4 : ∀ n : Nat, gerade n → gerade (n + 2) := by
  intro n h
  obtain ⟨k, hk⟩ := h
  exact ⟨k + 1, by omega⟩
```

</details>

## Aufgabe 3.5: Widerlege "Jede natürliche Zahl ist kleiner als 100".

<details>
<summary>Tipp 1</summary>

Drei Zeilen wie im Beispiel. Welche Zahl ist das Gegenbeispiel?

</details>

<details>
<summary>Tipp 2</summary>

`intro h`, dann `have h100 := h 100`, dann `omega`

</details>

<details>
<summary>Lösung dieser Aufgabe</summary>

```lean
theorem aufgabe_3_5 : ¬ (∀ n : Nat, n < 100) := by
  intro h
  have h100 := h 100
  omega
```

</details>

## Aufgabe 3.6: Widerlege "Jede natürliche Zahl ist gerade".

<details>
<summary>Tipp 1</summary>

Das Gegenbeispiel ist 1. Mit `intro h` wie oben bekommst du `h 1 : gerade 1`. Das ist ein Paar, das man mit `obtain` auspacken kann (wie in `beispiel_plus4`).

</details>

<details>
<summary>Tipp 2</summary>

`intro h`, dann `obtain ⟨k, hk⟩ := h 1` (hk : 1 = 2 * k), dann `omega`

</details>

<details>
<summary>Lösung dieser Aufgabe</summary>

```lean
theorem aufgabe_3_6 : ¬ (∀ n : Nat, gerade n) := by
  intro h
  obtain ⟨k, hk⟩ := h 1
  omega
```

</details>
