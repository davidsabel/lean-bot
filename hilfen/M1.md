## Aufgabe 1.1: Summe der Quadrate 0 + 1 + 4 + 9 + ... + n*n

<details>
<summary>Tipp 1</summary>

Fast wie bei `summe`. Was wird beim Schritt von n zu n + 1 dazugezählt?

</details>

<details>
<summary>Tipp 2</summary>

Statt `(n + 1)` kommt `(n + 1) * (n + 1)` dazu: `summeQuadrate n + (n + 1) * (n + 1)`

</details>

<details>
<summary>Lösung dieser Aufgabe</summary>

```lean
def summeQuadrate : Nat → Nat
  | 0     => 0
  | n + 1 => summeQuadrate n + (n + 1) * (n + 1)
```

</details>

## Aufgabe 1.2: Fakultät, fak n = 1 * 2 * ... * n

<details>
<summary>Tipp 1</summary>

Fall 0: Welche Zahl ändert ein Produkt nicht? Fall n + 1: Ersetze in `summe` das `+` durch `*`.

</details>

<details>
<summary>Tipp 2</summary>

`| 0 => 1` und `| n + 1 => fak n * (n + 1)`

</details>

<details>
<summary>Lösung dieser Aufgabe</summary>

```lean
def fak : Nat → Nat
  | 0     => 1
  | n + 1 => fak n * (n + 1)
```

</details>

## Aufgabe 1.3: Anzahl der Teilmengen

<details>
<summary>Tipp 1</summary>

Die leere Menge hat genau eine Teilmenge (sich selbst). Und ein neues Element verdoppelt die Anzahl: Jede alte Teilmenge gibt es einmal ohne und einmal mit dem neuen Element.

</details>

<details>
<summary>Tipp 2</summary>

`| 0 => 1` und `| n + 1 => 2 * teilmengen n`

</details>

<details>
<summary>Lösung dieser Aufgabe</summary>

```lean
def teilmengen : Nat → Nat
  | 0     => 1
  | n + 1 => 2 * teilmengen n
```

</details>
