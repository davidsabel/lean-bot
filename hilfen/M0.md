# Hilfen zu Mission 0

Erst selbst probieren! Klappen Sie die Hilfen nacheinander auf, nur so weit wie nötig.

## Aufgabe 0.1: Ein Droide verdreifacht seine Energie.

<details>
<summary>Tipp 1</summary>

Schau dir `verdopple` an. Was musst du ändern?

</details>

<details>
<summary>Tipp 2</summary>

Statt `2 * n` brauchst du `3 * n`.

</details>

<details>
<summary>Lösung dieser Aufgabe</summary>

```lean
def verdreifache (n : Nat) : Nat := 3 * n
```

</details>

## Aufgabe 0.2: die Fläche eines Rechtecks

<details>
<summary>Tipp 1</summary>

Die Funktion `energie` hat genau denselben Aufbau.

</details>

<details>
<summary>Tipp 2</summary>

Multipliziere die beiden Argumente: `breite * hoehe`.

</details>

<details>
<summary>Lösung dieser Aufgabe</summary>

```lean
def flaeche (breite : Nat) (hoehe : Nat) : Nat := breite * hoehe
```

</details>

## Aufgabe 0.3: Diesmal schreibst du die ganze Zeile nach `:=` selbst.

<details>
<summary>Tipp 1</summary>

Ein Argument wie bei `verdopple`, aber die Zahl wird mit sich selbst multipliziert.

</details>

<details>
<summary>Tipp 2</summary>

`n * n`

</details>

<details>
<summary>Lösung dieser Aufgabe</summary>

```lean
def quadrat (n : Nat) : Nat := n * n
```

</details>

## Aufgabe 0.4: Ab 50 Punkten ist ein Test bestanden.

<details>
<summary>Tipp 1</summary>

Wie `ampel`, aber mit nur einem `if ... then ... else ...`.

</details>

<details>
<summary>Tipp 2</summary>

`if punkte < 50 then "nicht bestanden" else "bestanden"`

</details>

<details>
<summary>Lösung dieser Aufgabe</summary>

```lean
def bewertung (punkte : Nat) : String :=
  if punkte < 50 then "nicht bestanden" else "bestanden"
```

</details>
